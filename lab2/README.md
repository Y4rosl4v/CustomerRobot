# Лабораторная работа 2 - Знакомство с роботом
In this lab, we will get acquainted with two parts of our robot, namely the Autonomous Mobile Robot P200 from YOUIBOT, which will be responsible for moving around the store, and the manipulator robot, which will be responsible for moving the product and scanning the QR code on it for the correct order. 

To make the introduction easier, we have provided documentation in the form of PDF files in this folder. We have thoroughly reviewed the documentation and learned how to interact with the robot. 

In our project, we plan to make the lower part of the robot, which is responsible for movement, move it to specific points that have been predefined. Once the robot reaches a specific point, it will interact with the product by scanning the QR code and moving it to a designated basket if it matches the order. 

In the next lab, we will explore the lower part of the robot in more detail and learn how to move it along a specific route.
