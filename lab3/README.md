# Лабораторная работа 3 - Передвижение робота
In this laboratory work, we have learned how to move the robot along specified points. This is done in the special YOUICompass interface, which opens in the browser after connecting to the robot via IP. 

After connecting to the interface, we go to the Maps section, where we create a map for our robot to follow. When creating the map, we manually move the robot around the area where it will operate, scanning and detecting obstacles to build the map. After our map is created, we can edit it by specifying points for completing tasks, movement directions, and other features directly on the map itself. It is important to initially define the robot's initial position on the map, which can be done automatically, and the robot will be ready to move. 

To make the robot move, we need to create a specific task in the Task management section, where we define the robot's sequence of actions. After everything is ready, we switch the robot to automatic mode and run the desired task. 

The robot starts moving! It travels through each specified point on the route and stops where necessary to complete other tasks.
